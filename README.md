# BionicPRO — Проектная работа 9 спринта

Решение состоит из двух заданий: повышение безопасности SSO и разработка сервиса отчётов.

## Структура репозитория

| Каталог | Назначение |
|---|---|
| `frontend/` | React-приложение для донастройки протеза (SSO, кнопка «Скачать отчёт») |
| `keycloak/` | Конфигурация Keycloak (realm, клиент с PKCE, брокеринг внешних IdP) |
| `ldap/` | Внешний источник учётных записей |
| `reports-service/` | Бэкенд-сервис `/reports`: отдаёт готовый отчёт из OLAP (ClickHouse) |
| `airflow/` | ETL-процесс: выгрузка из CRM в OLAP и построение витрины отчётности |
| `docs/diagrams/` | Диаграммы C4 в формате draw.io |

## Задание 1. Повышение безопасности

- Диаграмма C4 обновлённой схемы управления учётными данными (`docs/diagrams/`).
- Замена Code Grant на Authorization Code + PKCE во фронтенде и Keycloak.
- BFF-схема работы с токенами: access/refresh от IdP не попадают на фронтенд.
- Поддержка внешних IdP разных стран через брокеринг Keycloak.

## Задание 2. Сервис отчётов

- Диаграмма C4 подготовки и получения отчётов (`docs/diagrams/`).
- Airflow DAG: ETL из CRM в OLAP + витрина отчётности по пользователям.
- Бэкенд `/reports`: отчёт по пользователю из OLAP без тяжёлых вычислений в рантайме.
- Ограничение доступа: пользователь получает только собственный отчёт.
- Кнопка получения отчёта в UI.
